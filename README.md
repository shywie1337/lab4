# Greed Machine

Лабораторна робота №4.

## Запуск

Node.js 22 або новіший:

```sh
npm ci
npm run dev
```

Перевірка TypeScript і збірка:

```sh
npm run build
```

Публічний URL навчального API задано у `.env` як `VITE_API_URL`. У цьому файлі немає секретних ключів. Його потрібно додати до репозиторію разом із проєктом.

## Робота

Оберіть персонажа та створіть забіг. Список сесій зберігається в localStorage. Забіг можна відновити зі списку або за ID; перед підключенням виконується перевірка на сервері. Після перезавантаження відновлюється активна сесія.

Монети, бомби, шанс клину та результат дій визначає сервер. Після ігрової дії клієнт повторно отримує повний стан. Якщо стан не вдалося підтвердити, дії заблоковані до оновлення даних. Мережеві помилки й повідомлення сервера показує response interceptor. Request interceptor додає X-Session-ID.

Компоненти викликають composable `useGreed`, той — методи `greed.service`, які використовують Axios-клієнт. GreedMachine.vue надано викладачем; його оформлення збережено. Три барабани у слоті використовують DaisyUI countdown.

JavaScript із `payload.code` виконується через `new Function` згідно з умовою роботи. Це передбачено тільки для наданого навчального API. Потрібне підключення до сервера; локальна імітація ігрової механіки відсутня.
